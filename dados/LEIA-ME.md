# Pasta da planilha

Envie aqui a planilha **Base de Dados – Roadmaps – Para BI** (.xlsx), sempre com o mesmo nome,
para substituir a anterior. O painel (index.html) é gerado e publicado sozinho em 1 a 2 minutos.

Antes de enviar, apague a aba **Pontos Focais** da cópia: neste repositório público, a planilha
fica visível para qualquer pessoa.
